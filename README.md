# The Postcard

Who doesn't like postcards? This project is a fun and simple HTML5 and CSS3 exercise: a digital postcard you can share with your mom or your other half; they will be proud! :)

## 🖼️ What's in the postcard

- A header with a title and the 4Geeks logo.
- A body with a short message and a small form (name, email, comment).
- A footer with a "Send My Postcard" button.

## 📁 Project structure

```text
index.html   -> Markup for the postcard (header, body, footer)
styles.css   -> Styles for layout, colors, and spacing
learn.json   -> Metadata used by the learning platform
```

## 🚀 How to run it

Just open [index.html](index.html) in your browser, no build step required.

## 🎨 Customize it

- Change the text and images in [index.html](index.html) to make it your own.
- Try adding a different [Google Font](https://fonts.google.com/):
  1. Pick a font you like.
  2. Click **Get font**.
  3. Click **Get embed code**.
  4. Add the provided `<link>` tag to your HTML file.

## 🧠 Fundamentals covered

1. Basic structure for every HTML5 website.
2. The `link` tag to import CSS3 rules.
3. Using Google Fonts.
4. Using different selectors available in CSS3.
5. Working with containers or boxes: border, padding, and margins.
6. Overflow.
7. Using a simple form.
