# La Postal

¿A quién no le gustan las postales? Este proyecto es un ejercicio simple y divertido de HTML5 y CSS: una postal digital que puedes compartir con tu madre o con tu otra mitad, ¡ella/él se va a sentir orgullosa/o! :)

## 🖼️ Qué contiene la postal

- Un encabezado con un título y el logo de 4Geeks.
- Un cuerpo con un mensaje corto y un pequeño formulario (nombre, correo, comentario).
- Un pie de página con un botón "Send My Postcard".

## 📁 Estructura del proyecto

```text
index.html   -> Marcado de la postal (encabezado, cuerpo, pie de página)
styles.css   -> Estilos de layout, colores y espaciado
learn.json   -> Metadatos usados por la plataforma de aprendizaje
```

## 🚀 Cómo ejecutarlo

Simplemente abre [index.html](index.html) en tu navegador, no necesitas ningún paso de compilación.

## 🎨 Personalízalo

- Cambia el texto y las imágenes en [index.html](index.html) para hacerlo tuyo.
- Prueba a agregar una fuente distinta de [Google Fonts](https://fonts.google.com/):
  1. Elige la fuente que te guste.
  2. Haz clic en **Get font**.
  3. Haz clic en **Get embed code**.
  4. Agrega la etiqueta `<link>` proporcionada a tu archivo HTML.

## 🧠 Fundamentos cubiertos

1. Estructura básica para cada sitio web HTML5.
2. La etiqueta `link` para importar reglas CSS.
3. Uso de Google Fonts.
4. Uso de diferentes selectores disponibles en CSS.
5. Trabajar con contenedores o cajas: border, padding y margins.
6. Overflow.
7. Uso de un formulario simple.
